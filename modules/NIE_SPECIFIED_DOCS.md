"""
ДОКУМЕНТАЦИЯ: Класс NIESpecified для поиска цитаций

═══════════════════════════════════════════════════════════════════════════════

📌 НАЗНАЧЕНИЕ

Класс NIESpecified используется для автоматизированного поиска цитаций
в системе НИЕ (Número de Identidad de Extranjero) с указанием конкретного
региона (провинции) и офиса.

═══════════════════════════════════════════════════════════════════════════════

✅ ОСОБЕННОСТИ

1. Наследование от BaseVisa
   - Использует все методы базового класса (click_button, click_dropdown, enter_text)
   - Полная интеграция с логированием и обработкой блокировок

2. Полная логика из v1.0 в виде методов
   - close_cookie_popup() - закрытие cookies
   - select_provincia_and_accept() - выбор провинции
   - select_oficina_and_tramite() - выбор офиса и услуги
   - enter_person_data() - ввод паспорта, имени, года рождения
   - submit_form() - отправка формы (дважды)
   - check_citations_available() - проверка доступности цитаций
   - search_for_citations() - основной цикл

3. Обработка ошибок через RestartLoop
   - Каждая операция может выбросить RestartLoop
   - Цикл автоматически перезагружается после ошибки

4. Структурированное логирование
   - Каждый шаг логируется с разными уровнями
   - Счётчик попыток
   - Форматированный вывод

═══════════════════════════════════════════════════════════════════════════════

🚀 ИСПОЛЬЗОВАНИЕ

Базовый пример:

    from seleniumbase import Driver
    from modules.nie_specified import NIESpecified
    
    # Инициализируем браузер
    driver = Driver(uc=True)
    driver.uc_open_with_reconnect('https://...', 5)
    
    # Создаём экземпляр класса
    nie = NIESpecified(
        driver=driver,
        start_url='https://icp.administracionelectronica.gob.es/icpco/index',
        passport='FV315480',
        full_name='Yevhen Maksymov',
        birth_year='1991',
        provincia=3,      # Индекс в dropdown'е
        oficina=13,       # Индекс в dropdown'е
        tramite=5         # Индекс в dropdown'е
    )
    
    # Запускаем поиск
    nie.search_for_citations()

═══════════════════════════════════════════════════════════════════════════════

📋 ПАРАМЕТРЫ ИНИЦИАЛИЗАЦИИ

driver
    Selenium WebDriver объект (обычно от seleniumbase.Driver)
    Тип: WebDriver
    Обязательный параметр

start_url
    URL для перезагрузки при блокировке сайта
    Тип: str
    Пример: 'https://icp.administracionelectronica.gob.es/icpco/index'
    Обязательный параметр

passport
    Номер паспорта иностранца
    Тип: str
    Пример: 'FV315480'
    Обязательный параметр

full_name
    Полное имя (Фамилия Имя)
    Тип: str
    Пример: 'Yevhen Maksymov'
    Обязательный параметр

birth_year
    Год рождения (строка)
    Тип: str
    Пример: '1991'
    Обязательный параметр

provincia
    Индекс провинции в dropdown'е (SELECT по индексу)
    Тип: int
    Примеры:
        3 = ALICANTE
        5 = BARCELONA
        28 = MADRID
    Обязательный параметр

oficina
    Индекс офиса в dropdown'е (SELECT по индексу)
    Тип: int
    Пример: 13 = OEX ALICANTE
    Обязательный параметр

tramite
    Индекс типа услуги в dropdown'е (SELECT по индексу)
    Тип: int
    Пример: 5 = POLICÍA
    Обязательный параметр

═══════════════════════════════════════════════════════════════════════════════

🔄 ОСНОВНОЙ ЦИКЛ (search_for_citations)

Основной метод запускает бесконечный цикл со следующими шагами:

1. ⏳ Случайная задержка (4-7 секунд)
2. 📊 Увеличение счётчика попыток
3. 🚫 Проверка блокирующих состояний (429, редирект)
4. 🍪 Закрытие cookie popup'а
5. 🗺️ Выбор провинции + Accept
6. 🏢 Выбор офиса + услуги + Accept
7. 👤 Ввод паспорта, имени, года рождения
8. ✉️ Отправка формы (дважды)
9. 🔍 Проверка доступности цитаций
10. ✅ Если найдены → handle_citations_found()
11. ❌ Если не найдены → выход и перезагрузка цикла

═══════════════════════════════════════════════════════════════════════════════

🛡️ ОБРАБОТКА ОШИБОК

RestartLoop исключение:
    Выбрасывается при любой ошибке в процессе
    Автоматически перезагружает цикл
    Добавляет задержку 60-65 секунд перед новой попыткой

Блокирующие состояния:
    429 Too Many Requests → ждёт 310 секунд
    Редирект "Go Back" → ждёт 610 секунд
    Автоматически перезагружает страницу

Логирование:
    ✓ Успех (INFO) - зелёный цвет
    ✗ Ошибка (ERROR) - красный цвет
    ⚠️ Предупреждение (WARNING) - жёлтый цвет
    🎉 Цитации найдены (CRITICAL) - самый высокий уровень

═══════════════════════════════════════════════════════════════════════════════

📝 ЛОГИРОВАНИЕ

Все события логируются в файл logs/citas.log с форматом:
    2026-01-17 16:52:59 - modules.nie_specified - INFO - ✓ Цитации найдены

Уровни логирования:
    DEBUG   - Детальная информация о процессе (поиск элементов, ожидание)
    INFO    - Успешные операции (✓ элемент найден, кнопка нажата)
    WARNING - Предупреждения (⚠️ элемент не найден, используется default)
    ERROR   - Ошибки (✗ операция не удалась)
    CRITICAL - Критические события (🎉 цитации найдены!)

═══════════════════════════════════════════════════════════════════════════════

🔧 МЕТОДЫ КЛАССА

PUBLIC МЕТОДЫ:

search_for_citations()
    Запускает основной цикл поиска
    Параметры: нет
    Возвращает: ничего (бесконечный цикл)

PROTECTED МЕТОДЫ (для переопределения в подклассах):

close_cookie_popup(actions) -> bool
    Закрывает popup согласия с cookies
    
select_provincia_and_accept(actions) -> None
    Выбирает провинцию и нажимает Accept
    
select_oficina_and_tramite(actions) -> None
    Выбирает офис и тип услуги
    
enter_person_data(actions) -> None
    Вводит паспорт, имя, год рождения
    
submit_form(actions) -> None
    Отправляет форму (дважды)
    
check_citations_available(actions) -> bool
    Проверяет доступность цитаций
    Возвращает: True если найдены, False если нет
    
handle_citations_found()
    Обработчик когда цитации найдены
    Может быть переопределена для отправки в Telegram и т.д.
    
exit_and_restart(actions) -> None
    Нажимает кнопку выхода

УНАСЛЕДОВАННЫЕ МЕТОДЫ ИЗ BaseVisa:

click_button(actions, xpath, button_name, wait_time=0.5)
    Кликает по кнопке
    
click_dropdown(actions, xpath, option_value, dropdown_name=None)
    Выбирает опцию из dropdown'а
    
enter_text(actions, xpath, text, field_name=None)
    Вводит текст в поле
    
check_blocking_states() -> bool
    Проверяет блокирующие состояния

═══════════════════════════════════════════════════════════════════════════════

🚨 ВОЗМОЖНЫЕ ОШИБКИ И РЕШЕНИЯ

Ошибка: TimeoutException при поиске элемента
    Решение: Увеличить timeout в wait_clickable() или проверить XPath
    
Ошибка: 429 Too Many Requests
    Решение: Автоматическая обработка (ждёт 310 сек и перезагружает)
    
Ошибка: NoSuchElementException при выборе dropout'а
    Решение: Проверить индекс (может быть не по порядку)
    
Ошибка: RestartLoop в цикле
    Решение: Нормально, цикл перезагружается автоматически
