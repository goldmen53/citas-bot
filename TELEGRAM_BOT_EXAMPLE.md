# После запуска бота откройте Telegram и найдите вашего бота по username.
# 
# Команды доступные в боте:
#
# /start
# ───────────────────────────────────────────────────────────────────────────────
# Запускает бота и показывает главное меню
#
# Ожидаемый ответ:
# 
#   👋 Привет, Иван!
#   
#   Я помогаю автоматизировать поиск цитаций в испанских офисах.
#   
#   Доступные команды:
#   🔧 /register - Зарегистрироваться
#   🔍 /search - Начать поиск цитаций
#   📊 /status - Посмотреть статус
#   ⏹️ /stop - Остановить поиск
#   ❓ /help - Справка
#

# /help
# ───────────────────────────────────────────────────────────────────────────────
# Показывает подробную справку
#
# Ожидаемый ответ:
#
#   📚 СПРАВКА
#   
#   Команды:
#   🔧 /register - Зарегистрировать ваши данные
#   🔍 /search - Начать поиск цитаций
#   📊 /status - Статус текущего поиска
#   ⏹️ /stop - Остановить поиск
#   ❓ /help - Эта справка
#   
#   Как это работает:
#   1. Зарегистрируйте себя (/register)
#   2. Выберите тип визы и параметры
#   3. Начните поиск (/search)
#   4. Бот будет отправлять уведомления когда найдёт цитацию
#

# /register
# ───────────────────────────────────────────────────────────────────────────────
# Регистрирует вас в системе
#
# Процесс регистрации:
#   1. Введите полное имя: "Juan Jose Garcia Lopez"
#   2. Введите email: "juan@example.com"
#   3. Введите паспорт: "12345678A"
#   4. Введите год рождения: "1990"
#
# Ожидаемый ответ после регистрации:
#
#   ✅ Регистрация успешна!
#   
#   👤 Имя: Juan Jose Garcia Lopez
#   📧 Email: juan@example.com
#   🔢 Паспорт: 12345678A
#   📅 Год: 1990
#   
#   Теперь используйте /search для поиска цитаций.
#

# /search
# ───────────────────────────────────────────────────────────────────────────────
# Начинает процесс поиска цитаций
#
# Ожидаемый ответ:
#
#   🔍 Начало поиска
#   
#   Пользователь: Juan Jose Garcia Lopez
#   Паспорт: 12345678A
#   
#   Выберите тип визы:
#   
#   [НИЕ (с регионом)]  [НИЕ (национальный)]
#   [ТИЕ (с регионом)]  [ТИЕ (национальный)]
#
# После выбора типа визы:
#
#   ✅ Выбран тип: visa_nie_spec
#   
#   🔍 Начинается поиск...
#   
#   ⏳ Поиск выполняется. Я пришлю уведомление, когда найду цитацию.
#

# /status
# ───────────────────────────────────────────────────────────────────────────────
# Показывает текущий статус поиска
#
# Ожидаемый ответ:
#
#   📊 Статус
#   
#   ✅ Поиск активен
#   📍 Типы виз: НИЕ, ТИЕ
#   ⏱️ Работает: 2ч 45м
#   🔔 Уведомления: включены
#   
#   Я отправлю вам сообщение как только найду свободную цитацию!
#

# /stop
# ───────────────────────────────────────────────────────────────────────────────
# Останавливает поиск
#
# Ожидаемый ответ:
#
#   ⏹️ Поиск остановлен
#   
#   ❌ Все автоматические поиски отключены
#   📞 Вы можете связаться со мной командой /search для нового поиска

# ───────────────────────────────────────────────────────────────────────────────

# Ошибка: Бот не отвечает на сообщения
# ───────────────────────────────────────────────────────────────────────────────
# Решение:
#   1. Проверьте что бот запущен: ps aux | grep bot_handler.py
#   2. Проверьте логи: tail -f logs/citas.log
#   3. Проверьте интернет соединение
#   4. Проверьте что бот запущен с правильным токеном

# ───────────────────────────────────────────────────────────────────────────────

#   2. Убедитесь что токен скопирован полностью (всё до конца)
#   3. Получите новый токен у @BotFather если нужно
