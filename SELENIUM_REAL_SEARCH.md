## 🛠️ Как Работает Реальный Поиск (visa_nie_spec)

```python
# 1. В bot_handler.py пользователь выбирает тип визы
await async_search(
    passport="FV315480",
    full_name="Yevhen Maksymov",
    birth_year="1991",
    visa_type="visa_nie_spec",
    provincia=0,  # Это может быть провинция
    oficina=0,    # Это может быть офис
)

# 2. async_search() вызывает run_selenium_search() в ThreadPoolExecutor
# Это асинхронная функция из modules/selenium_runner.py

# 3. run_selenium_search() создает Chrome WebDriver
driver = webdriver.Chrome(options=chrome_options)
# Опции:
# - --headless (без графики, быстрее)
# - --no-sandbox (для Linux)
# - --disable-automation (скрывает что это бот)

# 4. Создает экземпляр NIESpecified с нашим драйвером
searcher = NIESpecified(
    driver=driver,
    start_url="https://icp.administracionelectronica.gob.es/icpco/index",
    passport=passport,
    full_name=full_name,
    ...
)

# 5. Запускает реальный поиск
citations = searcher.search_for_citations()
# Это метод в modules/nie_specified.py
# Он делает реальное взаимодействие с сайтом:
# - Заполняет форму
# - Нажимает кнопки
# - Ждет загрузки результатов
# - Парсит HTML

# 6. Возвращает результаты
return {
    'success': True,
    'citations': ['2026-01-20 14:30', '2026-01-21 10:00'],  # Реальные цитации или пусто
    'message': '✅ Найдено цитаций: 2',
    'error': None
}
```

## 🔧 Технические Детали

### Почему Поиск Долгий?

1. **Запуск Chrome (~3-5 сек)** - браузер должен инициализироваться
2. **Загрузка сайта (~2-5 сек)** - испанский сервис иногда медленный
3. **Заполнение формы (~2-3 сек)** - Selenium медленнее чем человек
4. **Парсинг результатов (~1-2 сек)** - зависит от скорости сети

**Итого:** 10-15 секунд обычно, до 2 минут если сайт перегружен

### Почему Это Не Mock

- ✅ Открывается реальный Chrome браузер (видно из логов "WebDriver создан")
- ✅ Заходит на реальный URL: https://icp.administracionelectronica.gob.es/icpco/index
- ✅ Парсит реальный HTML сайта
- ✅ Возвращает то что найдено (пусто если нет цитаций)
- ✅ Закрывает браузер после поиска (видно из логов "WebDriver закрыт")
