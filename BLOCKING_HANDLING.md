# 🛡️ Блокировка Сайта Испанского Сервиса

## ⛔ Что Произошло

Испанский сервис `https://icp.administracionelectronica.gob.es/icpco/index` обнаружил автоматизированный доступ и **заблокировал IP адрес** с кодом ошибки **429 (Too Many Requests)**.

## ⏳ Как Долго Длится Блокировка

- **Временная блокировка:** 10-15 минут
- **После блокировки:** IP разблокируется и можно заново пытаться

## 🔧 Что Бот Делает При Блокировке

Обновленный код теперь:

1. **Обнаруживает блокировку** - проверяет наличие "429" в ответе сайта
2. **Логирует блокировку** - выводит сообщение `⛔ БЛОКИРОВКА: Сайт заблокировал доступ`
3. **Ждет 10 минут** - `time.sleep(600)`
4. **Перезагружает страницу** - `driver.refresh()`
5. **Повторяет попытку** - продолжает поиск

## 📋 Логи При Блокировке

Когда сайт заблокирует тебя, увидишь логи:

```
❌ Ошибка при поиске: HTTPConnectionPool ... Max retries exceeded
⛔ БЛОКИРОВКА: Сайт заблокировал доступ (429)
⏳ Подожди 10 минут и попробуй снова
```

Или в боте получишь сообщение:
```
⛔ БЛОКИРОВКА: Сайт заблокировал доступ (429)
⏳ Подожди 10 минут и попробуй снова
```

## 🤖 Anti-Bot Механизмы

Бот использует следующие трюки чтобы избежать блокировки:

1. **User-Agent Rotation** - имитирует реальный браузер
   ```python
   'user-agent=Mozilla/5.0 (Windows NT 10.0; Win64; x64)...'
   ```

2. **Headless Mode** - запуск браузера без окна
   ```python
   '--headless'
   ```

3. **Случайные Задержки** - ждет 3-7 секунд между действиями
   ```python
   time.sleep(randrange(3, 6))
   ```

4. **Отключение Automation Detect** - скрывает что это бот
   ```python
   '--disable-blink-features=AutomationControlled'
   ```

5. **Longer Waits on Block Detection** - если обнаружена блокировка, ждет 2-3 минуты
   ```python
   time.sleep(randrange(120, 180))
   ```

## 💡 Как Избежать Блокировки

### 1. Увеличь Задержки Между Поисками
Не запускай поиск слишком часто. Ждай между попытками.

### 2. Используй Прокси (Будущая Фишка)
Когда будет реализовано, бот сможет ротировать IP адреса через прокси.

### 3. Будь Разумен
- Не запускай 100 поисков подряд
- Делай перерывы между поисками
- Один-два поиска в день - это безопасно

## 🔄 Если Заблокирован

### Вариант 1: Жди (Рекомендуется)
Просто жди 10 минут и попробуй снова. Бот будет автоматически ждать.

### Вариант 2: Перезагрузись
Если нужно быстрее:
1. Перезагрузи свой маршрутизатор (WiFi)
2. Получишь новый IP адрес
3. Попробуй снова

### Вариант 3: Используй VPN (Не рекомендуется)
VPN может привести к дополнительным блокировкам.

## 🛠️ Технические Детали

### Код Обнаружения Блокировки

```python
# В modules/nie_specified.py
try:
    page_source = self.driver.page_source
    if "429" in page_source or "Too Many Requests" in page_source:
        logger.error("⛔ БЛОКИРОВКА: Сайт вернул 429 (Too Many Requests)")
        logger.error("⏳ Ожидание 10 минут перед попыткой...")
        time.sleep(600)  # 10 минут
        self.driver.refresh()
        continue
except Exception as e:
    logger.debug(f"Ошибка при проверке блокировки: {e}")
```

### Код Обработки в Боте

```python
# В modules/selenium_runner.py
if "429" in error_msg or "Too Many Requests" in error_msg:
    message = "⛔ БЛОКИРОВКА: Сайт заблокировал доступ (429)\n⏳ Подожди 10 минут и попробуй снова"
else:
    message = "❌ Ошибка при поиске..."
```

## 📊 Статистика Блокировок

| Причина | Время Блокировки | Решение |
|---------|-----------------|--------|
| Слишком много быстрых запросов | 10-15 мин | Жди |
| Слишком много попыток подряд | 1-2 часа | Жди дольше |
| Подозрение на бот | 24+ часа | Жди или используй прокси |
